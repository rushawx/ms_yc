# Описание SQL-скриптов

Данный проект содержит два SQL-скрипта: `01_hive.sql` и `02_ch.sql`. Они предназначены для работы с различными базами данных и выполняют создание таблиц, а также выполнение аналитических запросов.

## Содержание файлов

### 01_hive.sql

Этот файл содержит SQL-запросы для работы с Hive. Основные действия:

1. **Создание таблиц:**
   - `logs_v2`: таблица для хранения логов с полями `log_id`, `transaction_id`, `category`, `comment`, `log_timestamp`.
   - `transactions_v2`: таблица для хранения транзакций с полями `transaction_id`, `user_id`, `amount`, `currency`, `transaction_date`, `is_fraud`.

2. **Аналитические запросы:**
   - Сумма транзакций по валютам (`USD`, `EUR`, `RUB`).
   - Сумма и среднее значение транзакций в зависимости от признака мошенничества (`is_fraud`).
   - Статистика транзакций по датам (`to_date(transaction_date)`).
   - Сумма транзакций по месяцам (`trunc(transaction_date, 'MM')`).
   - Количество логов для каждой транзакции с использованием `LEFT JOIN` между таблицами `transactions_v2` и `logs_v2`.

### 02_ch.sql

Этот файл содержит SQL-запросы для работы с ClickHouse. Основные действия:

1. **Создание таблиц:**
   - `orders`: таблица для хранения заказов с полями `order_id`, `user_id`, `order_date`, `total_amount`, `payment_status`.
   - `order_items`: таблица для хранения товаров в заказах с полями `item_id`, `order_id`, `product_name`, `product_price`, `quantity`.

2. **Аналитические запросы:**
   - Статистика заказов по статусу оплаты (`payment_status`).
   - Детализация заказов с подсчетом количества товаров, общей суммы и средней цены.
   - Статистика заказов по датам (`date(order_date)`).
   - Количество заказов для каждого пользователя.

## Как использовать

1. **Hive:**
   - Выполните скрипт `01_hive.sql` в Hive для создания таблиц и выполнения запросов.
   - Убедитесь, что данные загружены в таблицы `logs_v2` и `transactions_v2`.

2. **ClickHouse:**
   - Выполните скрипт `02_ch.sql` в ClickHouse для создания таблиц и выполнения запросов.
   - Убедитесь, что данные загружены в таблицы `orders` и `order_items`.

## Примечания

- Скрипты предполагают, что данные уже загружены в соответствующие таблицы.
- Для корректной работы запросов необходимо наличие данных в формате, соответствующем структуре таблиц.
